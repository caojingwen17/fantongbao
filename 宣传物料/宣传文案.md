## 一、一句话定位

**饭桶宝 —— 一家人的饭，一起搞定。**

从「今天吃什么」到「买菜、做菜」，一个微信小程序承包全家的一日三餐。

## 二、Slogan 候选

1. 一家人的饭，一起搞定（主推）
2. 今天也要好好吃饭
3. 菜谱、点菜、买菜、做菜，一条龙
4. 不再为「今天吃什么」吵架

## 三、目标用户

- 每天为「吃什么」发愁的家庭主厨 / 做饭搭子
- 小两口、三口之家、和父母同住的家庭
- 合租室友、拼饭搭子（同样可以建「家庭」）

## 四、用户痛点 → 我们的解法

| 痛点 | 饭桶宝的解法 |
| --- | --- |
| 「今天吃什么」是世纪难题，问一圈没人拿主意 | 家庭点菜单 + 邀请家人一起点菜 +「随机一道」抽卡，程序帮你做决定 |
| 家里的拿手菜散落在聊天记录、收藏夹和脑子里，想做时找不到 | 家庭共享菜谱库：菜名、展示图、食材、调料、备菜/做菜步骤，一次录入全家可用 |
| 网上刷到好菜谱（小红书/图片/文字），手动录入太麻烦 | AI 三种导入：拍照识别、粘贴文字识别、链接识别；只给个菜名也能自动生成家常菜谱 |
| 买菜漏买错买，好几天的菜混在一起算不清 | 买菜清单按食材/调料自动汇总勾选；多个点菜单「一起买」自动合并、重复菜标注；金额登记 + 多单分摊 |
| 做饭时步骤记不住，来回翻手机 | 做菜清单：步骤逐条勾选打卡，做完一键收工 |
| 想知道这个月伙食费花哪了 | 干饭日历：月度视图，每天吃了什么、花了多少一目了然 |

## 五、功能亮点 Top 6

1. **AI 菜谱导入**：拍照 / 文字 / 链接三种识别方式，外加「报个菜名就生成」，10 秒入库一道菜；文本+图片双重内容安全检测，放心用。
2. **家庭共享菜谱库**：4:3 展示图固定比例裁切，食材、调料、步骤结构化管理，全家共同维护。
3. **一起点菜**：点菜单支持邀请家人远程点菜，众口不再难调；不知道吃啥就「随机一道」，抽卡式决定今天吃什么。
4. **买菜清单 & 一起买**：待买的菜自动汇总成清单，食材调料分类勾选；多张点菜单可合并「一起买」，重复的菜自动标注；买完成本登记，金额自动分摊到各单。
5. **做菜清单打卡**：备菜、做菜步骤逐条勾选，厨房操作不手忙脚乱。
6. **干饭日历**：每天吃了啥、花了多少，月底回看一清二楚。
