# 饭桶宝 V1.0 正式版发布说明

**版本定位**：饭桶宝首个面向真实用户发布的**全功能正式版**，在微信小程序内完成「家庭菜谱 → 点菜 → 买菜 → 做菜」闭环，并支持菜谱分享与协作。

**技术栈**：微信原生小程序（WXML / WXSS / JS）+ 微信云开发（云函数、云数据库、云存储）。

**文档日期**：2026 年 3 月

---

## 一、需求背景

当代家庭吃饭往往要面对几类现实情况：**菜谱分散**在聊天记录、收藏夹、笔记 App 里，想做时不好找；**谁买菜、谁掌勺**口头约定容易忘；一顿多道菜时，**采购清单**容易漏项、重复或算不清；家人口味和备注**没法和「这一顿饭」绑在一起**。

饭桶宝以**家庭**为数据边界，把「家庭菜谱库」和「这一顿的点菜单」打通：先沉淀可复用的菜谱，再围绕**同一张点菜单**生成买菜清单与做菜清单，让协作有依据、进度看得见。小程序形态**免安装、微信内即用**，适合日常高频、轻量协作场景。

---

## 二、直击的用户痛点

| 痛点 | 饭桶宝的应对 |
|------|----------------|
| 菜谱到处存，难以统一管理与复用 | 按家庭维护菜谱库，支持搜索、编辑、展示图，数据云端同步 |
| 口头点菜容易乱，和采购脱节 | 点菜单承载「这一顿吃什么」，并与后续买菜、做菜状态联动 |
| 买菜清单靠脑补，易漏买、重复买 | 买菜清单按订单聚合食材与调料，支持勾选完成与额外采购项 |
| 做菜步骤记不住、多人协作难对齐 | 备菜 / 做菜步骤清单化，支持勾选进度，完成后订单闭环 |
| 好菜谱想分享给亲友家庭 | 分享海报 + 小程序码，扫码预览并导入到自家菜谱库 |
| 从零录入菜谱费时 | 支持多图 AI 识别、按菜名一键生成家常模板（可选，依赖云端 AI 配置） |

## 三、V1.0 功能总览

### 1. 账号与家庭

- **微信登录**：与云端用户体系绑定，支持会话缓存与静默登录体验（以实际实现为准）。
- **家庭**：创建家庭、加入家庭（邀请码）、切换家庭、查看成员；业务数据按家庭隔离，云函数侧校验成员身份。
- **家庭管理页**：维护多个家庭场景下的入口与信息展示。

### 2. 菜谱（核心资产）

- **菜谱列表**：当前家庭下的菜谱浏览与检索。
- **新增 / 编辑菜谱**：菜名、展示图（本地上传至云存储）、食材、调料、**备菜步骤**、**做菜步骤**。
- **导入能力（正式版已开放）**
  - **多图导入 · AI 识别**：一次最多 9 张图，上传后调用云端 AI（百炼等多模态能力，需配置 API Key）结构化提取；失败时可回退为通用模板提示用户编辑。
  - **AI 一键生成**：根据菜名生成可编辑的家常菜模板。
- **正式版刻意隐藏、后续可再开放的能力（代码与云函数仍保留，便于迭代）**
  - 小红书链接解析入口（合规解析未接入前不面向用户开放）。
  - 粘贴文案由 AI 提炼（`extractRecipeFromText`，与多图识别同属 AI 能力扩展）。
- **菜谱详情**：完整展示菜谱信息；支持分享图片、跳转编辑等。
- **分享与传播**
  - **生成分享海报**（画布导出）：含封面、步骤摘要、品牌与扫码文案、小程序码等（具体样式以线上为准）。
  - **扫码 / 链接进入分享落地页**：预览菜谱概要，选择家庭后**导入为家庭菜谱**（副本，带分享来源标识，以云端字段为准）。

### 3. 点菜与订单

- **首页**：当前家庭上下文、进行中的点单入口、常用菜谱与快捷入口；**吐槽与建议**入口（提交至云端 `feedback` 集合，区分吐槽/建议）。
- **点菜单 / 订单列表**：查看进行中与历史订单（待买菜 / 待制作 / 已完成等状态，与云端 `orders` 一致）。
- **点菜流程**：从菜谱选择菜品加入点菜单；支持备注；与订单详情、买菜、做菜页面联动。
- **订单详情**：查看本单菜品与备注；跳转买菜清单、做菜执行或点菜补充（以实际页面路由为准）。

### 4. 买菜与做菜（执行闭环）

- **买菜清单**：按订单聚合食材、调料，勾选完成；支持**额外采购项**的增删；完成后推进订单状态（以 `checklistFunctions` 与订单状态机为准）。
- **做菜清单**：备菜 / 做菜步骤勾选、进度推进，全部完成后订单进入已完成等终态。

### 5. 其他页面

- **登录页**：未登录时的授权与进入主页 / 家庭引导。
- **菜谱备注等辅助页**（若已接入订单）：与点单场景相关的备注能力（见 `pages/recipe/note` 等）。

### 6. 云端能力（实现侧摘要）

- **familyFunctions**：登录、家庭、成员、切换等。
- **recipeFunctions**：菜谱 CRUD、首页列表、分享 token / 小程序码准备、分享预览、分享导入等。
- **orderFunctions**：点菜单创建与维护、订单列表与详情、与待买菜订单的衔接等。
- **checklistFunctions**：买菜 / 做菜清单读写、勾选与订单完成推进。
- **aiFunctions**：按菜名生成家常菜谱、多图菜谱识别；链接 / 粘贴文案等分支保留作后续扩展。
- **initFunctions**（若使用）：集合与索引初始化。
- **feedbackFunctions**：用户提交吐槽/建议（写入 `feedback` 集合）。

## 四、发布与运维提示（建议）

- 小程序 **AppID**、云环境 **EnvId** 与 `app.js` 中 `wx.cloud.init` 一致。
- 部署并更新上述云函数（含 **feedbackFunctions**）；**aiFunctions** 需在云函数环境配置 **百炼 / DashScope** 等密钥后重新上传，否则 AI 相关能力将走兜底逻辑。
- 分享、小程序码涉及 **权限与 `recipeFunctions` 配置**（如 `wxacode.getUnlimited`），以微信开放平台与云函数 `config.json` 为准。
- 正式版对外文案与入口以**当前线上包**为准；本文档中「隐藏能力」仅说明产品策略，不排除后续小版本重新开放。

## 五、未来展望

1. **内容导入**：在合规前提下接入**笔记链接解析**，降低从站外「搬运」菜谱到家庭的成本。
2. **AI 能力**：持续优化多图识别准确率、步骤与调料分类；探索更贴合中餐习惯的默认模板与提示词。
3. **协作与提醒**：家庭成员分工、备餐提醒、订单留言等轻量协作能力。
4. **数据与体验**：搜索与分类、菜谱标签、家庭内「常吃菜」统计；性能与弱网体验优化。
5. **合规与版权**：对外分享与导入持续强调用户内容与平台规则，避免侵权与违规抓取。

## 六、结语

饭桶宝 V1.0 标志着从「能用的 demo」到「可长期运营的一版」：**菜谱沉淀 + 一顿饭的协作闭环**已经打通。后续迭代将在本版骨架上持续增强导入方式、AI 与协作体验。感谢内测与反馈，祝发布顺利。
